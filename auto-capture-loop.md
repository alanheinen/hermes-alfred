# Auto-Capture Loop

## Purpose
Automatically log significant events, errors, or learnings to improve performance and continuity.

### Conditions for Auto-Capture
When ANY of the following occur, append to `memory/error-log.md`:
1. A tool call fails or returns unexpected results.
2. User corrects you (e.g., "no, do it this way").
3. You discover a gotcha or undocumented behavior.
4. An assumption you've made turns out wrong.
5. Something takes way longer than expected.

### Format
- 🏷️ **Short title** — What happened. What to do instead.
